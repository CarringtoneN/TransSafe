# Vehicles UI Update

Updated the Fleet Management > Vehicles page to match the visual language used across the rest of TransSafe.

Changes:
- Consistent `rounded-2xl`, white cards and slate borders/rings.
- Compact table typography and spacing.
- Slate table header and hover rows.
- Compact icon actions using View/Edit/Delete icons instead of oversized text buttons.
- Consistent status badges for Active, Maintenance and Out of Service.
- Search field aligned with the rest of the Fleet Management pages.
- Blue `Add Vehicle` action consistent with other primary actions.
- Loading and error states displayed consistently.

No API, database, Prisma, or vehicle business logic was changed.
