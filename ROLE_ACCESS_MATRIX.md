# TransSafe Role Access Matrix

| Role | Dashboard | Allowed modules |
|---|---|---|
| Admin | Admin Dashboard | Entire system + User Management |
| Driver | Driver Dashboard | Individual Driver Profile, Individual Assignments, Individual Shifts, Vehicle Inspections, Incident Reports |
| Fleet Manager | Fleet Manager Dashboard | Fleet Management, Vehicles, Fleet Assets, Fuel Records, Documents |
| Operations & Scheduling Manager | Operations Dashboard | Trips, Vehicle Allocation, Driver Allocation, Manifest, Monitoring, Drivers, Assignments, Shifts, Vehicle Inspections, Incident Reports, Available Vehicles through allocation |
| Maintenance & Compliance | Maintenance Dashboard | Maintenance Schedule, Work Orders, Repairs, Service History, Compliance, Incident Reports, Vehicle Inspections |
| Technician / Mechanic | Technician Dashboard | Maintenance Schedule, Work Orders, Repairs, Service History, Incident Reports, Vehicle Inspections |

## Account creation
The Admin creates all non-admin accounts from **User Management > Create New User**.

Every new account receives the initial password:

`Trans#2026`

The login email is the email entered by the Admin, e.g. `john@transsafe.com`.
